# Bulua Hub — Barangay Bulua Community Information Website

> **⚠️ Notice:** *This platform and its repository files are strictly intended for a mini-project.*

Welcome to the official repository for **Bulua Hub**, a comprehensive multi-page community information platform dedicated to celebrating the service, heritage, and *bayanihan* of **Barangay Bulua**, the dynamic western gateway of Cagayan de Oro City, Philippines.

---

## 🔗 Live Demo

- **Explore Online:** [Bulua Hub Live Preview](https://cymrc.github.io/MiniProject1-BarangayWebsite/)

---

## 🗺️ Project Overview

**Bulua Hub** serves as an interactive digital directory and cultural archive for residents, visitors, and commuters. The platform bridges traditional heritage—such as Bulua's ancestral clay pottery industry—with the fast economic growth driven by its role as Northern Mindanao's major commercial transit hub.

---

## 📄 Key Pages Included

1. **`index.html` (Home):** Welcome portal featuring local service quick links, the latest updates on the annual pottery heritage showcase, and dynamic interactive announcements.
2. **`about.html` (History & Profile):** Chronicles Bulua's transformation from a coastal farming settlement named after its clear, bubbling freshwater springs into an urban economic center. Includes interactive highway perimeter maps.
3. **`officials.html` (Barangay Council):** The updated leadership organizational structure detailing elected administrative officials (Punong Barangay, Barangay Kagawads, and Sangguniang Kabataan).
4. **`attractions.html` (Notable Landmarks & Culture):** Showcases structural highlights including the Westbound Public Terminal, San Roque Parish Church, local pottery stalls, and educational foundations (Bulua National High School and Bulua Central Elementary School).
5. **`contact.html` (Services & Contact Directory):** Public service matrices detailing processing timelines for Barangay Clearances, Indigency Certificates, emergency hotlines, and public office contact parameters.
6. **`sources.html` (Bibliography & Registries):** A clean documentation index anchoring all administrative text records, emergency contact registries, and third-party media asset providers.

---

## ✨ Features

- **Responsive Architecture:** Built with modern, pure HTML5 semantic structures scaled using fluid layouts (`meta name="viewport"`).
- **Public Service Matrix:** Clear tabular listings specifying requirements and processing speed windows (e.g., 5-10 minute clearances) for local civil documents.
- **Emergency Directory:** Quick-reference emergency blocks with prominent contact fields for the Bulua Rescue Core, Police Station 7, and BHERT Medical Units.
- **Interactive Geolocation Embeds:** Integration with Google Maps to visually chart boundary perimeters, the Westbound highway corridors, and the central Barangay Hall complex.
- **Pure CSS Enhancements:** 
  - Accordion-style toggle notice boards built entirely via pure CSS checkbox techniques (`input[type="checkbox"]` + label pairings) without heavy JavaScript payloads.
  - Floating scroll-to-top contextual action buttons (`href="#top"`) for seamless document navigation.
- **Standardized Footer Matrix:** Multi-column information hierarchy mapping quick links, local office hours, and official social media paths uniformly across all pages.
